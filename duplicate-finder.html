How to Use

  1. Upload your Excel or CSV file using the file upload option.
  2. Click the Load File button to process the uploaded file.
  3. The duplicate analysis results will appear in the table below.
  4. Use the following filters to view the required records:
    • 🔁 Duplicates – Displays only duplicate records.
    • ✨ Unique – Displays only unique records.
    • 📑 All Data – Displays the complete dataset.
  5. You can copy or download the currently displayed results at any time.

Important

If you use the Download Preview feature and then wish to apply a different filter, please upload the file again before filtering.

Applying new filters without re-uploading the file may cause the downloaded output to match the previously generated download preview data instead of the newly selected filter results.
